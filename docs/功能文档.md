# RustScan 功能文档

## 项目概述
RustScan 是一个以 Rust 编写的快速端口扫描器，专注于在极短时间内并发探测大量端口。命令行帮助强调不要在无法承受高并发连接的敏感环境中使用，并给出了社区入口与源码地址。工具的基本使用形式为 `rustscan [OPTIONS]`，通过参数控制目标、端口范围与输出形态。【F:src/input.rs†L50-L140】【F:src/main.rs†L44-L135】

## 命令行参数
RustScan 通过 `clap` 定义了丰富的命令行开关，可细粒度控制扫描输入、速度和输出形式。【F:src/input.rs†L50-L200】

- **目标地址**：`-a/--addresses` 接受以逗号分隔的地址、CIDR 或主机名，也支持文件路径；`-x/--exclude-addresses` 可排除给定网段或主机。地址解析会在内部展开 CIDR、解析域名，并去重和排除指定网络。【F:src/input.rs†L64-L136】【F:src/address.rs†L19-L125】
- **端口选择**：通过 `-p/--ports` 指定端口列表，`-r/--range` 指定起止范围，默认扫描 1-65535；`--top` 可配合配置文件的端口列表实现热门端口扫描；`-e/--exclude-ports` 排除端口；`--scan-order` 控制顺序或随机扫描。【F:src/input.rs†L68-L140】【F:src/port_strategy/mod.rs†L1-L95】
- **性能参数**：`-b/--batch-size` 控制并发连接数，`-t/--timeout` 设置端口判断超时时间，`--tries` 指定重试次数，`-u/--ulimit` 自动提升文件句柄上限以匹配高批次扫描；在类 Unix 环境下会根据 ulimit 自动调整批量大小并给出提示。【F:src/input.rs†L99-L118】【F:src/main.rs†L65-L213】
- **输出与交互**：`-g/--greppable` 输出纯端口列表（便于管道），`--accessible` 输出无色彩、面向读屏器，`--no-banner` 关闭 ASCII 艺术标题，`--no-config` 忽略配置文件，这些选项会影响启动时的展示逻辑。【F:src/input.rs†L88-L96】【F:src/main.rs†L50-L168】
- **DNS 与协议**：`--resolver` 支持自定义逗号分隔的 DNS 服务器或从文件读取；`--udp` 切换到 UDP 模式，根据内置 payload 表探测响应端口。【F:src/input.rs†L96-L98】【F:src/input.rs†L130-L140】【F:src/scanner/mod.rs†L175-L199】

## 配置文件合并
RustScan 会自动读取配置文件（默认 `~/.rustscan.toml`，支持 `--config-path` 自定义）并与命令行参数合并。若未使用 `--no-config`，CLI 中未显式设置的必填选项会被配置文件覆盖；可选项如端口、解析器、排除列表等仅在配置存在值时合并。启用 `--top` 时会使用配置文件提供的端口集合作为热门端口表。若配置解析失败，程序会提示错误并退出，以避免在不确定参数下继续扫描。【F:src/main.rs†L44-L87】【F:src/input.rs†L143-L285】

## 地址解析与排除
`parse_addresses` 会遍历命令行给出的目标：

1. 直接解析 IP；
2. 解析 CIDR 并展开全部主机；
3. 解析域名（优先使用系统解析器，不可用时改用 `--resolver` 指定的 DNS 或 Cloudflare TLS）；
4. 将未解析成功的字符串视为文件路径，从文件中逐行读取地址。

解析完成后，函数会根据排除列表将命中的 CIDR 或主机过滤掉，并通过有序集合去重，确保不会对同一地址重复扫描。【F:src/address.rs†L36-L125】

## 扫描流程与结果输出
`Scanner::new` 会结合端口策略（顺序、随机或自定义列表）生成最终扫描序列，并按批量大小并发扫描。扫描时会：

- 使用 `FuturesUnordered` 并发连接，并在连接完成后补充新的任务，直至遍历所有 IP 与端口组合；
- TCP 模式下为每个端口进行最多 `tries` 次连接尝试并在成功后立即关闭套接字；
- UDP 模式下根据端口匹配内置 payload，发送后等待响应并通过超时判断是否开放；
- 遇到常见错误会汇总记录，当批量数超过 ulimit 时提示用户调低批量或提升限制；
- 在非 greppable 模式下，通过 `detail!` 宏输出 `Open ports for <IP>: [p1,p2,...]`，greppable 模式直接打印 `IP -> [port,...]`；
- 若某个 IP 未发现开放端口，会针对批量或超时设置给出排障建议。【F:src/scanner/mod.rs†L1-L199】【F:src/main.rs†L115-L135】

## 日志与基准
程序在 `RUST_LOG=info` 下会输出扫描阶段的计时摘要；遇到配置缺失、ulimit 过低或地址解析失败时会通过 `warning!` 宏提示用户。`Benchmark`/`NamedTimer` 用于统计端口扫描与结果展示的耗时，帮助用户根据环境调优参数。【F:src/main.rs†L40-L137】
